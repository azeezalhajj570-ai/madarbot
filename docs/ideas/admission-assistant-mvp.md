# Admission Intelligence Platform — Confirmed Product Direction

## Product Thesis
A vertical intelligence system for Saudi admission providers that transforms community conversations into insights, answers, and decisions.

**Not:** AI chatbot, Telegram automation tool, or generic agent platform.

## Value Chain
**Understand → Find → Act**

## MVP Boundary (Phase 1)
**Build:** Fast retrieval, knowledge extraction, insights, source-backed answers, human feedback.
**Skip:** WhatsApp, Odoo, CRM, marketing automation, student-facing apps.

## Execution Order
1. Search Foundation (Week 1-2)
2. Structured Knowledge (Week 3-4)
3. AI Layer (Week 5-6)
4. Pilot (Week 7-8)

## North Star Metric
**Time from question → useful decision.**

## Validation Goal
Within 60 days, one Saudi admission consultant uses the platform weekly and says it improves their daily decision-making.

## Risk
Building sophistication before proving which workflow creates daily value.
